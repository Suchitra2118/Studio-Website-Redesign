# 📸 Studio Website Redesign

A premium wedding photography website redesign created in **Figma** during my **UI/UX Internship at SkillCraft Technology**. This project focuses on improving user experience, visual hierarchy, navigation, branding, and booking conversion through a modern and elegant interface.

# 📌 Project Overview

The goal of this project was to redesign the homepage of Studio with a clean, premium, and user-friendly experience.

The redesign enhances the overall visual appeal while making it easier for users to explore wedding photography services, browse portfolios, and book photography sessions.

# 💡 Objectives

- Improve visual hierarchy
- Create a premium wedding theme
- Increase user engagement
- Simplify navigation
- Showcase wedding photography professionally
- Increase booking requests
- Improve overall user experience


# 🚀 Design Process

The project followed a complete UI/UX workflow:

1. Project Overview
2. Business Goals & UX Audit
3. Low-Fidelity Wireframes
4. Design System
5. High-Fidelity Prototype
6. Final Homepage Design
